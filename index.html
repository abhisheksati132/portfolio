Secure Cross-Device Sync & PWA

Klipport Universal Clipboard

A secure cross-device clipboard and sync platform for real-time transfers of text, files, and images. Features browser-side end-to-end encryption (AES-GCM / PBKDF2) via the Web Crypto API, an offline service-worker cache, account-free WebSocket pairing with a 6-digit PIN, and serverless password and timer enforcement on stored data.

  • End-to-end encryption stays entirely in the browser
  • 6-digit PIN pairing, no account required
  • Works offline as an installable PWA
