Cryptographic Sync & PWA

Klipport Universal Clipboard

Cross-device sync utility for real-time text, file, and media transfer. Leverages browser-native Web Crypto API (AES-GCM / PBKDF2) for zero-knowledge end-to-end encryption. Pairs clients via 6-digit PIN over WebSockets with offline Service Worker support.

Cryptographic Pipeline
  1. Client-Side Derivation: Key derived via PBKDF2; encryption uses AES-GCM in the browser. Plaintext never touches network.
  2. PIN Pairing: Node.js relay handles discovery via ephemeral 6-digit tokens without user accounts.
  3. Encrypted Vault: Supabase stores ciphertext with server-enforced countdown timers.

P2P Encrypted Mesh & WebRTC

Whispr Encrypted Space

Private peer-to-peer communication suite featuring full-duplex WebSocket messaging, WebRTC DTLS audio/video channels, and ephemeral auto-expiring media. Operates strictly under zero-knowledge principles where the relay server never inspects decrypted data.
